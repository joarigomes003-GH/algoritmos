## Pseudocódigo

1. Somar dois números

Início  
  ler A  
  ler B  
  resultado ← A + B  
  escrever resultado  
Fim  

---

2. Verificar se número é par ou ímpar

Início  
  ler número  
  se número % 2 = 0 então  
    escrever "par"  
  senão  
    escrever "ímpar"  
Fim  

---

3. Calcular média de 3 notas

Início  
  ler n1  
  ler n2  
  ler n3  
  média ← (n1 + n2 + n3) / 3  
  escrever média  
Fim
